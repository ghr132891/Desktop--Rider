# Win11 真机测试清单

GitHub Actions 的 Windows 运行器已经验证了壁纸设置、桌面层挂接、动态壁纸、视频图层、露白填充、遮挡暂停、重启恢复与清除（见 `README.md` 的「验证」）。下面是运行器**测不到**、需要在真机上看的部分。拉取仓库到 Win11 电脑后按本文操作，结果按编号反馈即可。

## 1. 准备

两种方式任选：

**A. 装安装包（最接近用户）**
1. GitHub 仓库 → Actions → 最新一次绿色的「Windows client」运行 → Artifacts → 下载 `DesktopRider-windows-x64`。
2. 解压，运行 `Desktop Rider Setup *.exe`（NSIS 安装）或直接运行便携版 exe。没有代码签名，SmartScreen 会拦一次：更多信息 → 仍要运行。

**B. 从源码运行（方便改代码重试）**
```bat
cd client\windows
npm ci
npm start
```
需要 Node 20 或更新，Windows PowerShell 5.1（系统自带）。`npm test` 与 `npm run smoke` 可先跑一遍确认环境。

数据目录：`%APPDATA%\desktop-rider-windows\`
- `settings.json`：开机启动、节能暂停
- `desktop\layers.json`：桌面层记录；`desktop\` 下还有写出的壁纸 PNG、叠加 PNG、`*-live-*` 视频、`*-clip-*` 图层视频

## 4. 节能策略（锁屏 / 电池 CI 无法触发）

先放一个动态壁纸或至少一个视频图层并应用，确认视频在桌面上动。

| # | 操作 | 预期 |
|---|---|---|
| 4.1 | Win+L 锁屏，几秒后解锁 | 解锁后视频继续；锁屏期间 CPU 应降到接近空闲（任务管理器看 Desktop Rider 进程） |
| 4.2 | 笔记本拔掉电源 | 2 秒内视频暂停（画面停在当前帧）；插回电源后继续 |
| 4.3 | 关闭「节能暂停」，再拔电源 | 不暂停 |
| 4.4 | 最大化任意窗口再还原 | 暂停、继续；半屏窗口不算遮挡 |
| 4.5 | 全屏播放一个视频 / 游戏再退出 | 同 4.4 |
| 4.6 | 睡眠再唤醒 | 唤醒后视频继续播放，层窗口位置不变 |

## 7. 桌面歌词（运行器没有播放器，跟随播放只能真机测）

先在网页侧栏「桌面歌词」里打开显示歌词、来源选「跟随正在播放（客户端）」，应用到显示器。

| # | 操作 | 预期 |
|---|---|---|
| 7.1 | QQ音乐播放一首有歌词的歌（显示方式选「卡拉 OK 逐字点亮」） | 几秒内桌面出现当前句并按字点亮（QQ音乐逐字歌词解密成功），面板状态行显示「正在播放「歌名」· 歌手 · 歌词来自QQ音乐（逐字）」；若某首歌只有逐行歌词，整句按时长线性点亮 |
| 7.2 | 网易云音乐播放 | 同上 |
| 7.3 | 切歌、暂停、拖进度条 | 歌词跟着换 / 停 / 跳，偏差在 1 秒内（SMTC 位置每秒同步一次） |
| 7.4 | 歌词站选「QQ音乐」或「网易云音乐」 | 重新应用后状态行的来源随之变化；某站没有这首歌时有提示 |
| 7.5 | 「指定歌曲」填入歌名 + 歌手 | 无论播放器在放什么，都用这首歌的歌词 |
| 7.6 | 「时间微调」±1 秒 | 歌词提前 / 延后 |
| 7.7 | 来源选「手动 LRC」粘贴歌词 | 播放器有会话时跟随其进度，没有时自行循环 |
| 7.8 | 字体选「自定义」填写已安装字体名（如 霞鹜文楷） | 桌面上的歌词用该字体；预览与桌面一致 |
| 7.9 | 五种切换方式与过渡时长；「多行舞台」3 / 5 行 | 桌面上切句、舞台滑动与预览一致；邻句变暗变模糊 |
| 7.12 | 间奏超过 5 秒的歌 | 间奏期间出现三个呼吸点并逐个点亮 |
| 7.13 | 底衬 30% 以上 | 歌词后面有磨砂深色条，文字更清楚 |
| 7.10 | 同时开动态壁纸 / 视频图层 | 歌词在视频之上；遮挡暂停时歌词也停住，恢复后继续 |
| 7.11 | 播放器退出 | 歌词消失（无会话） |

记录：播放器名称与版本、是否被识别（状态行）、歌词匹配是否正确（匹配错歌时记下歌名 / 歌手与搜索到的结果）。

## 8. 失败时带回的信息

- 操作编号、现象、截图（整个桌面）。
- `%APPDATA%\desktop-rider-windows\settings.json` 与 `desktop\layers.json`。
- Windows 版本：设置 → 系统 → 关于 → OS 内部版本（如 26100.xxxx）。
- 性能相关：任务管理器里 Desktop Rider 各进程的 CPU / GPU / 内存数字。
- 层窗口有无、位置：可在源码方式下运行 `node test/windows.cjs`，它会把桥脚本回查到的父窗口、矩形、暂停状态写进 `test\out\report.json` 并截图。
