# Win11 真机测试清单

GitHub Actions 的 Windows 运行器已经验证了壁纸设置、桌面层挂接、动态壁纸、视频图层、露白填充、遮挡暂停、重启恢复与清除（见 `README.md` 的「验证」）。下面是运行器**测不到**、需要在真机上看的部分。拉取仓库到 Win11 电脑后按本文操作，结果按编号反馈即可。

**进度（2026-11-02，Win11 10.0.26200，中文系统，1920×1080 单屏）**：`npm test`、`npm run smoke`、`node test/windows.cjs` 在真机上全部通过（壁纸、桌面层、露白填充、视频图层、遮挡暂停、卡拉 OK 歌词、萌版人物窗口与 HTTP API、逐帧人物提取、重启恢复、清除、壁纸还原）。这一轮发现并修复了两个只在真机上出现的问题：
- `native/bridge.ps1` 没有 UTF-8 BOM 时，中文系统的 Windows PowerShell 5.1 按 GBK 解码内嵌 C#，`Add-Type` 编译失败，客户端完全无法工作（运行器是英文系统所以没暴露）。已修复并加单元测试守住 BOM（`75e310e`）。
- 后台开着但没在播放的 QQ音乐 会让 SMTC 报告「位置 0、未播放」，手动 LRC 的桌面歌词因此停在第一句。现在只有「正在播放 / 暂停」状态的会话才驱动歌词时钟，停止或刚打开的播放器视为无会话（自行循环）。
下面第 3–8 节的人工项仍待验证。

## 1. 准备

两种方式任选：

**A. 装安装包（最接近用户）**
1. GitHub 仓库 → Actions → 最新一次绿色的「Windows client」运行 → Artifacts → 下载 `DesktopRider-windows-x64`。
2. 解压，运行 `Desktop Rider Setup *.exe`（NSIS 安装）或直接运行便携版 exe。没有代码签名，SmartScreen 会拦一次：更多信息 → 仍要运行。

**B. 从源码运行（方便改代码重试）**
```bat
cd client\windows
npm ci
npm start
```
需要 Node 20 或更新，Windows PowerShell 5.1（系统自带）。`npm test` 与 `npm run smoke` 可先跑一遍确认环境。

数据目录：`%APPDATA%\desktop-rider-windows\`
- `settings.json`：开机启动、节能暂停
- `desktop\layers.json`：桌面层记录；`desktop\` 下还有写出的壁纸 PNG、叠加 PNG、`*-live-*` 视频、`*-clip-*` 图层视频

## 7. 桌面歌词（运行器没有播放器，跟随播放只能真机测）

**2026-11-08 修复后复测：测试对象是 Desktop Rider，QQ音乐 22.13 作为播放源。**

- 已修复：仅对 QQ音乐满足有效曲目/时间线及明确播放控制条件的异常 `Changing` 状态兼容；媒体检查间隔降为 250ms；切歌先清旧词并隔离旧请求；播放时按有效更新时间校正，暂停恢复和换曲各自重建时间基准；退出清空文字、逐字元素、索引和媒体状态。
- 自动化：44 项客户端测试及 Electron 烟测通过。异常状态采用上一轮捕获的状态模式回归，并通过真实控制器与共享歌词渲染器验证。此次真机播放未出现异常 `Changing`，不能把未重现当作已实测触发了兼容分支。
- 真机：同机、同两首歌，真实 Electron 桌面挂接、真实 SMTC 与在线歌词，100ms 采样，共 3913 个样本、约 6.5 分钟。播放/暂停/恢复/退出首次渲染层观测响应为 0.282–0.599 秒，暂停稳定段的逐字进度不变。向前拖动为 0.482 秒；向后拖动和暂停后拖动分别为 1.343、1.481 秒，完整交互仍不能一概判定满足 1 秒目标。
- 两次较慢拖动中，系统提供的新位置更新时间分别在输入调用后 1.222、1.421 秒，桥仅晚 31、9ms 收到。证据指向本次 QQ音乐/SMTC 的时间线发布较晚；Desktop Rider 收到新位置后已及时转交渲染层。这些时间包含输入执行和采样误差，不是录音对齐测量。
- 切到新歌后，旧词在首次新曲目回调后的 92ms 内已被观察到清空；切回时 121ms 内已换成缓存的新词。首次新歌歌词在输入后 1.365 秒可见，在线取词等待仍取决于服务响应。退出后 `lines=0`、`index=-1`、文字为空、逐字元素为空且层隐藏；临时层、监听及测试配置目录均已清理。
- 本地证据：`.test-results/real-players-fix-2026-11-08/`，包括 `unit.log`、`smoke.log`、截图及本轮 `samples.jsonl` / `analysis.json`。网易云未安装，未测试；没有验证音频与逐字高亮的高精度对齐、长时间连续播放或多播放器竞争。

## 9. 失败时带回的信息

- 操作编号、现象、截图（整个桌面）。
- `%APPDATA%\desktop-rider-windows\settings.json` 与 `desktop\layers.json`。
- Windows 版本：设置 → 系统 → 关于 → OS 内部版本（如 26100.xxxx）。
- 性能相关：任务管理器里 Desktop Rider 各进程的 CPU / GPU / 内存数字。
- 层窗口有无、位置：可在源码方式下运行 `node test/windows.cjs`，它会把桥脚本回查到的父窗口、矩形、暂停状态写进 `test\out\report.json` 并截图。
