# Desktop Rider

一个用来验证桌面 DIY 体验的中文交互原型。无构建步骤；人物分割使用项目内固定版本的 MediaPipe JS / WASM 与模型，无需 npm 安装或运行时联网；所有壁纸、设置与方案均在本地处理。

## 启动

在本目录执行：

```sh
python3 tools/serve.py
```

打开 http://127.0.0.1:4173 。服务仅监听本机回环地址。也可以使用 `npm start`。

## 已实现

- 完整、垂直、斜切三种桌面布局。
- 分裂角度 −80° 至 80°、横纵控制点 1% 至 99%、间距 0 至 60px，以及间隙颜色。实际左右区域面积单独显示。
- 点击「在画面上选分割位置」自由落点；控制点支持二维拖动，两端可拖动调整角度。方向键微调，Shift 加速。
- 普通模式可独立设置原图切分点（5%–95%）。壁纸先按桌面比例裁切，再拆成左右两部分；开启联动后，每部分等比铺满自己的分区，随分区大小、斜切角度和间距重新定位与缩放。关闭联动时保持整张壁纸固定，只移动裁切边界。预览、模板缩略图与导出共用同一套图像映射。
- 人物优先：本机识别人像，人物沿用统一取景并随控制点整体平移，分割缝经过人物后方。联动时预留 18% 取景余量，边缘会适量裁切。背景位移配合保护带羽化，避免将人物分别缩放或出现重复轮廓。支持识别状态和失败重试。
- 人物悬浮：在本机识别画面主体并抠出为独立图层，可在预览中直接拖动、滚轮缩放、方向键微调，支持水平翻转与投影；原位置用周边颜色补全背景。自动识别使用人像模型找到起点，再用 MediaPipe MagicTouch 点选模型生成高清轮廓，插画、线稿同样可用；「调整抠图范围」中点击添加、右键或切换「去除」后点击减去。抠图点、位置、大小随方案保存，导出 PNG 时人物绘制在悬浮位置。
- 从 Wallpaper Engine 导入：选择创意工坊 431960 文件夹（或单个壁纸），列出全部壁纸。场景壁纸在本机解析 scene.pkg，取出其中最大的 PNG / JPEG / LZ4 RGBA 图层（原始分辨率）；视频壁纸拖动滑块选一帧；网页壁纸及其他类型使用预览图。导入后与本地图片一样参与分裂、人物优先与人物悬浮。
- 4 张项目内原创 SVG 山景壁纸、1 张人像实拍壁纸与 4 套布局；导入 JPG / PNG / WebP，最高 20 MB，导入后最长边缩至 2000px。
- 16:10、16:9、4:3 比例与 100% 至 160% 壁纸缩放，支持横、纵取景调整。
- 最多 3 个收纳分区、每区 6 个示例快捷项；支持拖入分区、点击或 Enter 移至下一区、按类型整理。
- 方案命名、保存、恢复、删除；自动保存工作草稿，刷新前同步待保存修改。
- 导出 1600px 宽 PNG 分裂壁纸，16:10 时为 1600×1000。只导出壁纸，不含示例图标、分割手柄与界面。
- 全屏预览、窄屏布局、键盘焦点、减少动态效果偏好。

## 当前边界

这是浏览器交互原型，并不是已经接管操作系统桌面的应用。

- 收纳分区展示的是示例快捷项，不会移动、删除或打开真实文件。
- 导出的 PNG 可以由用户在系统设置中设为壁纸；本原型不会直接改动系统壁纸。
- 数据保存在当前浏览器、当前来源的 localStorage 中，没有账户和云同步。更换端口、浏览器或清除站点数据会失去这些方案；请导出重要壁纸。
- 用户壁纸作为压缩图片存入方案，浏览器存储容量有限。空间不足时会提示，不会假装保存成功。
- 人物悬浮的背景补全是多尺度颜色扩散，不是 AI 修补：大面积人物移走后，原位置会留下柔和、偏模糊的色块轮廓。人物悬浮只存在于预览和导出图中，不会成为系统桌面上的独立窗口。
- Wallpaper Engine 场景只取单个图层，不还原图层叠加、粒子、动效与脚本；DXT 压缩纹理暂不支持，此时可选预览图。导入的画面压缩到最长边 2000px 存入浏览器。
- 尚未实现多显示器、系统窗口吸附、开机启动、桌面图标接管。

下一阶段需要先确认主平台（Windows 或 macOS），再实现原生桌面层、文件权限、显示器枚举与系统壁纸应用；浏览器界面和分裂几何逻辑可以继续复用。真实文件整理应优先使用快捷方式并保留可撤销记录。

## 文件

- `index.html`：页面结构、控件与弹窗。
- `styles.css`：工作台样式与响应式布局。
- `app.js`：裁切几何、壁纸渲染、交互、导入导出、本地存储。
- `portrait.js`：人物保护、距离场、背景合成；预览与导出共用。
- `person-worker.js`：在 Worker 中运行本地人物分割模型。
- `cutout.js`：人物悬浮的点选蒙版合并、透明人物图层与背景补全。
- `wallpaper-engine.js`：读取 Wallpaper Engine 文件夹、解析 scene.pkg / .tex 纹理。
- `assets/`：内置壁纸及本地人物分割模型。
- `vendor/mediapipe/`：固定版本运行库与许可证。
- `docs/portrait-algorithms.md`：算法调研、选型、具体实现与限制。
- `tools/create_wallpapers.py`：生成项目内矢量壁纸。
- `tools/serve.py`：仅本机可访问的开发服务器。
- `tools/verify.cjs`：浏览器行为与导出验证，依赖当前开发环境的 Playwright 和 Chrome。
- `artifacts/desktop-design.png`、`artifacts/mobile-design.png`：验证时的页面截图。

## 已验证

执行 `node --check app.js` 与 `node tools/verify.cjs`。浏览器验证涵盖分裂设置、鼠标拖动、键盘调整、联动开关、导出间隙像素、模板、分区、方案保存/恢复/删除、图片导入后立即刷新、PNG 下载、390px / 1024px 页面宽度以及帮助弹窗。浏览器运行期间无未捕获错误。

壁纸联动专项回归：`node tools/verify-wallpaper.cjs`。使用坐标编码图片检查左右画面随比例变化、关闭联动后保持固定、零间距等分时还原原图；覆盖 24 种极端布局无露底，并比较浏览器预览与 PNG 导出中的采样像素。联动开关对比截图保存在 `artifacts/wallpaper-linked.png` 和 `artifacts/wallpaper-unlinked.png`。

人像测试壁纸「林间人像」的摄影来源和裁切说明见 `assets/CREDITS.md`。开启「人物优先」后，40° 斜切仍保持所识别人物的原始比例；发丝、透明边缘等效果受模型精度影响。此模式让缝隙从人物后方经过，并非让人物任意迁移或自动补全背景。

人物与分割交互回归：`node tools/verify-portrait.cjs`。普通模式和人物模式的测试与限制详见 `docs/portrait-algorithms.md`。

人物悬浮与 Wallpaper Engine 导入回归：`node tools/verify-float.cjs`。覆盖自动抠图、背景补全、拖动 / 滚轮 / 键盘、导出位置、刷新恢复、点选添加 / 去除，以及用测试生成的 scene.pkg（内嵌 PNG 与 LZ4 原始 RGBA 纹理）验证文件夹扫描和图层解码。

拖动画面回归：`node tools/verify-drag-motion.cjs`，检查鼠标尚未松开时画面已经更新（含垂直线纯纵向拖动），并验证人物整体变换、关闭联动和导出一致性。
