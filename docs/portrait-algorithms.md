# 人像壁纸分裂：算法选择与已实现行为

检索、实现与验证日期：2026-10-22。

## 问题与结论

原实现以画面正中间为原图切分点，让左右原图分别覆盖左右目标多边形。两边的缩放倍数不同，会让脸部、身体发生错位或被边界裁掉。调整切线角度加剧这一问题，增加间距并不能修复。

当前增加「人物优先」：使用人物分割置信度建立人物层与保护邻域。人物沿用统一的原图取景，开启壁纸联动时与画面整体随控制点平移；分割间隙在人物后方经过。背景向两侧小幅位移，人物周围用距离场平滑恢复为原图，避免平移背景中的人物副本形成重影。这是基于分割结果的工程组合方案，并非下面任一论文的完整复现。

## 比较过的方案

| 方案 | 适合用途 | 本项目判断 |
| --- | --- | --- |
| 各分区独立等比裁切 | 抽象图、山景、允许错位的图像 | 保留为普通分裂模式；可自行指定原图切分位置 |
| Seam Carving（内容感知重定向） | 依据重要性删除/插入图像中的像素路径 | 原文支持重要内容权重和人工引导，但需要更完整的保护能量及失败评估；本次没有实现，也不让它直接重采样脸部 |
| 人物分割 + 统一取景 + 背景位移与保护邻域混合 | 人物应保持连续、分割线允许经过人物后方 | 本次实现。不会独立缩放人物的两半，人物轮廓取决于模型精度 |
| 完整抠图 + 背景修补 + 独立人物层 | 大幅挪动人物、重新构图 | 背景修补需要估计原本被人物遮挡的区域。本次未生成或修补这部分内容 |

## 已实现的计算流程

1. 本地 Worker 加载固定版本 MediaPipe Tasks Vision 0.10.21 与 Selfie Segmenter 模型。图片转为 ImageBitmap 后仅在本机 Worker 中处理。
2. 输出人物置信度，以 smoothstep(0.25, 0.75) 形成软掩膜。识别结果按图片缓存，拖动参数不重复推理。
3. 原图和掩膜共用一次等比 cover 取景及用户指定的横、纵取景位置。开启联动的分裂模式预留 18% 的取景余量，控制点横纵位置驱动整幅画面平移，偏移量限制在图像覆盖范围内。人物两侧的缩放完全一致，平移过程中缩放倍数固定；代价是画面边缘会额外裁切。关闭联动恢复固定取景。
4. 对掩膜生成两次扫描的近似欧式距离场。人物周围保护带包含位移量，再增加羽化区域，使背景中的人物副本不会被平移到轮廓外。
5. 背景在切线两侧沿法线方向平移各半个间距，边缘用镜像延展覆盖空缺。人物周围按照保护带恢复原图；间隙内只按人物软掩膜恢复人物。
6. 预览与 PNG 导出调用同一个渲染器。切线、手柄、桌面图标和辅助 UI 不写入导出。

## 分割位置与交互

- 控制点 `(ratio, anchorY)` 可在 1%–99% 的横、纵范围指定。角度绕此点改变。
- 可以点击「在画面上选分割位置」后点击画面，或者直接拖动控制点。
- 两个端点可以拖动以改变角度与位置；允许 ±80°，防止接近水平时数值不稳定。
- 横、纵位置滑块与方向键提供精细控制，Shift+方向键每次移动 5%。
- 面板显示多边形的实际左右面积，避免把控制点横坐标误当作面积比例。
- 普通分裂模式可以展开「原图切分位置」，独立设置原图 5%–95% 的切分比例。人物优先时隐藏该项，因为人物使用统一取景。
- 旧方案载入时补全新字段；旧的内置人像草稿默认启用人物优先，原有角度、间距和位置保留。

## 验证与局限

`tools/verify-portrait.cjs` 使用真正的本地模型，并验证人物像素、预览/导出一致性、自由选点、二维拖动、端点拖动、键盘、刷新、旧方案、失败重试、无外部网络请求和窄屏布局。当前照片中掩膜完全不透明的人物像素随当前取景范围变化，导出与同一整体变换后的原图进行比较，不将人物平移误判为形变。

这不是所有照片的准确率指标。发丝、手指、半透明衣物、遮挡、多人、低对比度等情况仍可能误分；无人物时会提示。识别失败时显示完整原图并提供重试，不会假装保护成功；导出/保存失败会明确提示。统一 cover 取景仍可能裁掉原图边缘，可调整壁纸取景，但不会恢复输入照片之外的内容。

人物优先的产品取舍是：人物跨越分割缝时优先保持连续，因此分割缝在人物处会中断。如果用户要求缝隙始终贯穿整个画面，应关闭人物优先，此时人物也可能被切开。

控制点画面联动专项回归：`tools/verify-drag-motion.cjs`。在鼠标仍按住时读取实际预览像素，验证垂直线的纯纵向拖动和横向拖动均改变画面；检查人物整体缩放不变、关闭联动后取景固定、预览与导出一致，以及刷新恢复。拖动时显示辅助分割线，辅助线不导出。
